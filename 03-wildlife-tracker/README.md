# Wildlife Tracker

A simple wildlife tracking application built as part of the **freeCodeCamp JavaScript Certification** curriculum.

## 📚 What I Learned

* Creating and working with objects
* Accessing and modifying object properties
* Using nested data structures
* Working with arrays and objects together
* Managing structured data
* Using functions to manipulate object data

## 🎯 Objective

The objective of this workshop is to practice working with JavaScript objects by creating and managing structured information about different wildlife species.

## 🛠️ Technologies Used

* JavaScript

## ✨ Main Features

* Store information about wildlife species
* Access animal data through object properties
* Modify existing data
* Work with nested objects and arrays
* Manage structured wildlife records
