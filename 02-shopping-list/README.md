# Shopping List

A simple shopping list application built as part of the **freeCodeCamp JavaScript Certification** curriculum.

## 📚 What I Learned

* Creating and working with arrays
* Accessing array elements
* Adding and removing items from an array
* Updating array data
* Using array methods
* Working with functions and arrays

## 🎯 Objective

The objective of this workshop is to practice working with JavaScript arrays by creating and managing a simple shopping list.

## 🛠️ Technologies Used

* JavaScript

## ✨ Main Features

* Create a shopping list
* Store multiple items in an array
* Access individual items
* Modify the shopping list
* Add and remove items
